# Segurança e Governança

## Controles
- S3 Block Public Access.
- Criptografia.
- Versioning.
- IAM least privilege.
- KMS quando houver justificativa.
- Cognito para autenticação.
- CloudTrail para auditoria.
- CloudWatch para logs/métricas/alarmes.
- Macie apenas se houver caso de uso real de descoberta de dados sensíveis.

## Governança de IA
- Respostas fundamentadas.
- Referenciar fontes.
- Não responder como fato sem evidência.
- Diferenciar campos observados de campos inferidos por IA.
- Considerar revisão humana para baixa confiança/conteúdo crítico.
